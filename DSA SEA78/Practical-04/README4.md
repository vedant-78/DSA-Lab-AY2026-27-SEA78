Decimal to Binary Conversion Using Stack
Algorithm

Start the program.

Read a decimal number n from the user.

Initialize a stack array s and set top = -1.

Repeat while n is not equal to 0:

Calculate the remainder r = n % 2.

Divide n by 2.

Increment top.

Store the remainder r in the stack.

Print the binary number.

Traverse the stack from top to 0.

Print each stored remainder to obtain the binary representation.

End the program.
