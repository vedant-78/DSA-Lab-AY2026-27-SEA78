Student Database Management System
Algorithm

Start the program.

Define a stud structure to store:

Roll number

Student name

Program

Subject names

Subject marks

Total marks

Average marks

Create an array of student structures.

Display a menu with three options:

Create

Display

Search

For Create:

Read the number of students.

Accept each student's details.

Calculate the total marks.

Calculate the average marks.

Store all information in the structure array.

For Display:

Traverse the student array.

Display the details of each student.

Display total and average marks.

For Search:

Accept a student's roll number.

Traverse the student array.

Compare each student's roll number with the entered roll number.

If a match is found, display STUDENT FOUND.

If no match is found, display STUDENT NOT FOUND.

Repeat the menu until the user selects an option greater than or equal to 3.

End the program.
