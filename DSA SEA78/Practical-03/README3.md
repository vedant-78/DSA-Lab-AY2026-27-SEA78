Contact Management and Searching
Algorithm

Start the program.

Define a Contact structure containing:

Contact name

Phone number

Create an array to store contact records.

Read the number of contact records.

Input the name and phone number for each contact.

Display all contact records.

Ask the user to enter a name to search.

Perform Sequential Search:

Start from the first contact.

Compare the entered name with each contact name using strcmp().

If a match is found, display the corresponding phone number.

If no match is found, display Contact not found.

Sort the contacts alphabetically by name using Bubble Sort.

Perform Binary Search:

Set low = 0 and high = n - 1.

Calculate the middle position.

Compare the search name with the middle contact name.

If they match, display the corresponding phone number.

If the search name is smaller, search the left half.

If the search name is larger, search the right half.

Repeat until the contact is found or low > high.

Display whether the contact was found or not using Binary Search.

End the program.
