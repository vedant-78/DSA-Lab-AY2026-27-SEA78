C Pattern Programs
Algorithm
1. Number Triangle Pattern

Start the program.

Initialize i and j.

Run an outer loop from i = 1 to 4.

For each row, run an inner loop from j = 1 to i.

Print the value of j.

Move to the next line after each row.

End the program.

2. Number Diamond Pattern

Start the program.

Set n = 4.

Run an outer loop from i = 1 to n to create the upper half.

Print spaces before the numbers to center the pattern.

Print the number i, i times.

Run another outer loop from i = n - 1 down to 1 to create the lower half.

Print spaces and then print the number i, i times.

End the program.

3. Star Triangle Pattern

Start the program.

Set n = 4.

Run an outer loop from i = 1 to n.

Print spaces before the stars to align the pattern.

Run an inner loop to print i stars.

Print a new line after each row.

End the program.

4. Alphabet Diamond Pattern

Start the program.

Set n = 4.

Run an outer loop from i = 0 to n - 1.

Initialize the character as A for each row.

Print spaces before the characters to center the pattern.

Print characters in increasing order from A.

Print characters in decreasing order to form the second half of the row.

Move to the next line.

End the program.
